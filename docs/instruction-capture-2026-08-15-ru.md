# Снималка трафика по приложениям — инструкция оператору (Redmi 10, MIUI)

Шаг 0 спрашивает: **каким биржам реально продаётся трафик твоего телефона**. Статическую половину
уже сняли по коду приложений (39 из 66 несут рекламные SDK). Эта инструкция — про вторую половину:
**счётчики с провода**, приложение → хост, с числом наблюдений.

Всё делаешь ты сам. Мы к телефону не прикасаемся. Ничего необратимого здесь нет: захват
выключается одной кнопкой, приложение удаляется без следов.

---

## 0. Что произойдёт

PCAPdroid поднимает **локальный** VPN — наружу ничего не уходит, весь разбор идёт на самом
телефоне. Он записывает, **какое приложение к какому хосту подключалось**. Содержимое соединений
не расшифровывается: нам нужны только имена хостов, этого достаточно.

Пока PCAPdroid пишет, **другой VPN на телефоне работать не сможет** — Android разрешает только один
VPN одновременно. Если ты обычно держишь VPN включённым, на время сбора он будет выключен.

## 1. Установка

1. Поставить **PCAPdroid** — F-Droid (`https://f-droid.org/en/packages/com.emanuelef.remote_capture/`)
   или Google Play, пакет `com.emanuelef.remote_capture`. Платные функции (Firewall, Malware
   detection, pcapng) **не нужны**, покупать ничего не надо.

## 2. Настройки — ДО запуска (это важнее самого запуска)

Меню слева → **Настройки**:

2. **«Макс. логируемых соединений»** — поставить **максимум из списка**. По умолчанию 8192, и на
   активном телефоне этого хватает меньше чем на сутки: старые соединения молча выбрасываются, и в
   выгрузке их уже не будет. Молча — это и есть проблема: файл выглядит полным.
3. **«Показывать полное содержимое» (Full payload) — выключено.** Ест память, нам не нужно.
4. *(желательно)* **«Блокировка QUIC» → «всегда».** Часть рекламных запросов идёт по QUIC, откуда
   имя хоста достаётся не всегда; с этой галкой приложения откатываются на обычный TLS, где имя
   видно. Возвращается обратно одним переключателем.
5. **«Целевые приложения» — оставить ПУСТЫМ.** Мы не знаем заранее, какие приложения тебя продают;
   фильтр здесь означал бы, что ответ уже известен.

## 3. MIUI — чтобы система не убила захват

MIUI агрессивно убивает фоновые процессы (Xiaomi у dontkillmyapp в самой проблемной группе). Три
действия, ровно в этом порядке:

6. **«Безопасность» → Разрешения → Автозапуск** → включить для PCAPdroid (по умолчанию выключен).
7. **Настройки → Расширенные настройки → Батарея и производительность → Выбор ограничений для
   приложений → PCAPdroid → «Без ограничений»**.
8. В недавних задачах **закрепить карточку PCAPdroid замком** (потянуть вниз), чтобы «очистить всё»
   её не закрывало. Уведомление PCAPdroid не смахивать — пока оно висит, захват жив.

## 4. Запуск

9. Вкладка **«Состояние»** → **«Запустить»** → разрешить VPN.
10. Дальше — **обычный день**. Открывать то, чем реально пользуешься, включая приложения с рекламой.
    Специально ничего делать не надо: чем обычнее день, тем честнее таблица.

## 5. Выгрузка — В КОНЦЕ КАЖДОГО ДНЯ, не раз в неделю

11. Вкладка **«Соединения»**.
12. **Убрать фильтр и очистить поиск**: лупа — стереть текст и закрыть; значок фильтра → «Изменить
    фильтр» → «Сбросить». Это обязательно: выгрузка сохраняет **ровно то, что показано на экране**,
    и отфильтрованный файл выглядит точно так же, как полный.
13. Меню (⋮) → **«Сохранить как CSV»** → сохранить в **Downloads (Загрузки)**. Имя подставится само
    (`PCAPdroid_15_авг._18_42_07.csv`) — менять не надо.
14. **Дальше ничего не делай — файл заберём сами** по ssh с телефона (шелл у нас уже есть, спасибо).
    Просто скажи в чат, что выгрузил. Если ssh почему-то не отвечает — пришли файл в Telegram
    **как файл**, не как фото.
15. Захват **не останавливать** — он продолжится. На следующий день повторить пункты 11–14.

## 6. Что прислать вместе с первой выгрузкой

16. Скриншот вкладки **«Состояние»** — там видно, сколько времени шёл захват. Это единственное
    доказательство, что MIUI его не убил; «вроде работало» доказательством не является.
17. Через сутки — Настройки → Батарея → расход по приложениям → сколько съел PCAPdroid. Мы этого
    нигде не измеряли и выдумывать не будем: твоя цифра и будет измерением.

## 7. Как всё выключить

18. «Состояние» → «Остановить». Уведомление исчезнет, VPN снимется, обычный VPN снова заработает.
    Если включал **Block QUIC** — вернуть в `never`. Приложение можно удалить: следов в системе,
    кроме сохранённых CSV, не остаётся.

---

### Что мы с этим сделаем

Из CSV берутся ровно два поля на строку — **имя пакета** и **имя хоста** — и считается, сколько раз
какое приложение к какому хосту ходило. Дальше хост сопоставляется с организацией и с ответом на
вопрос «а есть ли у неё OpenRTB-биржа, куда пускают внешнего покупателя». Это и есть таблица,
ради которой шаг 0 существует.

Чего в этом файле НЕ будет: содержимого соединений (оно не расшифровывается), и ничего с чужих
устройств — снимается только твой телефон. Строки системного резолвера (`netd`) не приписываются
никакому приложению: там хост есть, а приложения нет, и врать про это мы не будем.
